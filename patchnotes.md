# Patch Notes

## 2026-06-02 — Video backgrounds, sound & one-click join

- Brand-new home screen with a **looping video background** that shuffles through multiple clips.
- **Sound controls** — hover the speaker for a volume slider (75% by default). The background audio fades out smoothly when you launch the game and comes back when you close it.
- Added **Patch Notes / Documentation / Rules** tabs, a clickable logo that opens the [website](https://gamingalliance.net), and a **[Discord](https://discord.gg/3jqpTSctJJ)** button.
- **Settings** now also adjusts background-video sound; **Verify files** lives there too.
- The server is added to your in-game multiplayer list automatically, and the launcher connects you straight in.

---

## 2026-05-31 — Faster launches & fresh look

- **Much faster startup.** The launcher no longer re-checks every file from scratch — unchanged installs now launch almost instantly.
- Added a **Verify files** button to force a full integrity check and repair.
- Added a **Settings** dialog to choose how much RAM Minecraft uses (4 GB minimum, 8 GB recommended).
- New launcher home screen with patch notes, documentation and a [Discord](https://discord.gg/3jqpTSctJJ) link.

---

## 2026-05-30 — Initial release

- First public build of the GamingAlliance launcher.
- Auto-installs the modpack and connects you straight to the server.
